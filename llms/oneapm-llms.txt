# OneAPM

> OneAPM (Beijing Blueware Technology / 北京蓝海讯通科技, founded 2008) is a Chinese application performance management (APM) and intelligent IT operations vendor. It instruments applications and infrastructure end to end via language-specific agents and delivers monitoring, log analytics, alerting and AIOps as SaaS or on-premise to 60,000+ enterprise users.

Generated by the API Evangelist enrichment pipeline from the catalog profile (method: generated, 2026-07-20). OneAPM publishes instrumentation agents (SDKs), not a public REST API; no OpenAPI, OAuth, or /.well-known discovery surface was found.

## Products
- [Application Insight](https://www.oneapm.com/ai/): server-side, code-level tracing (Java, .NET, PHP, Python, Node.js, Ruby, Go)
- [Browser Insight](https://www.oneapm.com/bi/): real user / front-end performance monitoring
- [Mobile Insight](https://www.oneapm.com/mi/): mobile application performance
- Infrastructure Insight, Network Insight, LogInsight, Cloud Alert (OneAlert), Cloud Test, OneITSM, Intelligence Insight (I² AIOps)
